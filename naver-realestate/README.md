# 부동산 시세 트래커 (네이버부동산)

지역명이나 지하철역을 입력하고 **아파트 / 오피스텔 / 빌라**와 **매매 / 전세**를 고르면, 주변 단지의
네이버부동산 **현재 호가**와 **실거래가**, **변동률**을 HTML 화면으로 정리해 줍니다.

## 실행

```bash
python3 server.py            # Python 3.8+만 있으면 됩니다 (추가 설치 없음)
```
그 다음 브라우저에서 http://localhost:8000 접속.

- `python3 server.py --demo` : 가짜 데이터로 화면만 확인
- `MOLIT_API_KEY=인증키 python3 server.py` : (선택) 국토부 실거래가 API 사용.
  빌라 실거래는 이 키가 있어야 나옵니다. 키는 공공데이터포털(data.go.kr)에서
  "국토교통부_아파트/오피스텔/연립다세대 매매 실거래가 자료"를 활용신청하면 받을 수 있습니다.

`index.html`만 더블클릭해서 열면 동작하지 않습니다. 네이버부동산이 브라우저 직접 호출(CORS)을
막기 때문에 `server.py`가 중간에서 대신 호출합니다.

## 보여주는 것
- 호가 평당가(중앙값), 최근 3개월 실거래 평당가
- 실거래 변동률: 최근 3개월 vs 직전 3개월, 전년 동기 대비
- 호가 괴리율: 호가가 실거래보다 몇 % 높거나 낮은지
- 월별 평당가 추이 차트, 단지별 표(정렬 가능), 현재 매물 목록, 최근 실거래 목록
- 5분마다 자동 새로고침 옵션

## 참고
- 네이버부동산 비공식 내부 API를 사용합니다. 네이버가 구조를 바꾸면 동작이 멈출 수 있고,
  요청이 많으면 일시 차단(429)될 수 있어서 요청 사이에 간격을 두고 5분 캐시를 씁니다.
- 개인 참고용으로만 쓰세요. 대량 수집이나 재배포는 네이버 이용약관에 어긋날 수 있습니다.
